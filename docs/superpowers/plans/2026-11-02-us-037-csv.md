# US-037 CSV Implementation Plan

> **For agentic workers:** Execute inline using executing-plans.

**Goal:** Export company-scoped draft/final statement CSVs from list and detail, localized and audited.
**Architecture:** A repeatable-read transaction loads statement metadata and S1 license/adjustment lines and commits an export audit before returning CSV. A read-only server action validates authorization and supplies the existing download URL; the download endpoint independently reauthorizes.
**Tech Stack:** Next.js, Drizzle, PostgreSQL, Vitest.
