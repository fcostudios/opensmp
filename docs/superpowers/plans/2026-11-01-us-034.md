# US-034 license-only close implementation plan

> **For agentic workers:** Use executing-plans for inline implementation in the supplied worktree.

**Goal:** Finance can run and rerun a monthly license-only close with durable CloseRun evidence.
**Architecture:** Shared exact daily proration in domain; an authenticated transaction service writes scoped statements and deterministic lines, preserving finals. Existing /cierre hosts the manual form and latest run duration.
**Tech Stack:** Next.js 16, Drizzle/PostgreSQL, Zod, Vitest/fast-check.
**Spec:** docs/stories/sprint-2/r1_misc_us_034.md; docs/specs/08_scope.md US-034; BR-02/17/18.

## Global constraints
- Only US-034; license lines only (DEC-SMP-065/066). No usage, finalization, export or statement-list implementation.
- All company data uses authorization.companyIds; only central_finance/group_admin may close.
- Append-only migrations; preserve finals and audit writes atomically.
- Production sprint exit requires separate human Finance/IT acceptance.

## Review focus
- Transfer on day 10 and rate changes must cover every billable day exactly once.
- February/leap years and fractional cents must use integer arithmetic and deterministic rounding.
- Missing rates fail the entire draft update; failure run survives rollback.
- Concurrent reruns and finalization cannot duplicate or mutate final evidence.
- Forged company identifiers, unauthorized roles, and latest-run reads cannot cross scope.
